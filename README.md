# A/B-тест обложки карточки Ozon по рекламному CTR

Локальное приложение: подключаешь свой кабинет Ozon, загружаешь несколько
вариантов обложки, приложение по очереди ставит их на карточку, собирает показы
и клики из рекламы и показывает, у какой обложки CTR выше и значима ли разница.

## Как это работает

- Обложка меняется по расписанию: вариант A → B → C → … → снова, блоками
  (по умолчанию 3 дня), несколько циклов. Второй и последующие циклы идут в
  перемешанном порядке — чтобы отделить эффект обложки от дня недели и конкурентов.
- «Переключение» = перестановка уже одобренных фото в карточке (первое = обложка),
  повторной модерации при этом нет.
- Раз в 30 минут фоновая задача (`worker.py` через launchd) ставит нужный вариант,
  тянет дневную статистику рекламы из Performance API и пересчитывает отчёт.
  Первые сутки каждого блока не учитываются (переходный период).
- Статистика рекламы посуточная, поэтому переключения выровнены по полуночи МСК.

## Установка

Нужен Python 3.11+ (в macOS обычно есть). В папке проекта:

```bash
pip3 install -r requirements.txt
python3 app.py
```

Откроется браузер на `http://127.0.0.1:8765`. Дальше всё в интерфейсе.

### Что понадобится

1. **Ozon Seller API** — Личный кабинет → Настройки → Seller API: `Client-Id` и `Api-Key`.
2. **Ozon Performance API** — раздел Реклама → «...» → API → создать пару ключей
   (`Client-Id` вида `...@advertising.performance.ozon.ru` и `Client-Secret`).
3. **GitHub — репозиторий и токен.** Ozon скачивает картинки по ссылке (иногда не
   сразу, а из очереди модерации), поэтому нужны постоянные ссылки. Приложение
   кладёт фото в твой репозиторий и раздаёт через CDN jsDelivr (работает из РФ,
   в отличие от ImgBB).
   - **Репозиторий:** [github.com/new](https://github.com/new) → имя `ozon-covers`
     → **Public** → галочка **Add a README file** → **Create**. В поле приложения:
     `твой-логин/ozon-covers`.
   - **Токен:** [github.com/settings/tokens](https://github.com/settings/tokens) →
     **Generate new token → classic** → Note: `ozon-covers`, Expiration: подольше →
     отметить scope **`public_repo`** → **Generate token** → скопировать строку
     `ghp_…` в поле «GitHub — токен». (Токен показывается один раз; когда истечёт —
     загрузка фото перестанет работать, сделать новый.)

## Порядок работы в интерфейсе

1. **Подключение** — вставить ключи, «Сохранить», «Проверить подключение» (три галочки).
2. **Товар** — ввести артикул, «Найти» (покажет текущую обложку).
3. **Рекламные кампании** — «Загрузить список», отметить кампании продвижения в поиске.
4. **Варианты обложки** — выбрать файлы, «Добавить». Фото уедут в GitHub, появятся превью.
5. **Параметры теста** — длина блока, число циклов и т.д. Внизу — оценка длительности.
6. **Запуск**:
   - «Залить фото в карточку» → подождать модерации Ozon → «Проверить готовность».
   - «Старт теста» (дата по умолчанию — ближайшая полночь МСК).
7. **Мониторинг** — расписание, текущий блок, кнопка «Обновить сейчас».
8. **Результаты** — CTR по вариантам, значимость, вывод. Кнопка «сделать обложкой».

## Фоновая ротация 24/7

Приложение `app.py` — только интерфейс, его можно закрывать. Саму ротацию делает
отдельная фоновая задача. Установить (один раз):

```bash
./install_service.sh
```

Она запускает `worker.py` каждые 30 минут, **пока Mac включён**. Пропуски не
страшны: переключение раз в несколько дней, а первые сутки блока всё равно
отбрасываются. Логи — `data/worker.log`.

Удалить службу:
```bash
launchctl unload ~/Library/LaunchAgents/com.ozon.cover-abtest.plist
rm ~/Library/LaunchAgents/com.ozon.cover-abtest.plist
```

## Командная строка (не обязательно)

```bash
python3 status.py            # где сейчас тест, расписание
python3 rotate.py --dry-run  # что сделала бы ротация сейчас
python3 worker.py            # разовый прогон: ротация + сбор + отчёт
python3 ozon_performance.py campaigns   # список кампаний
```

## Ограничения метода

- **Тест по времени слабее одновременного сплита.** На CTR влияют день недели,
  сезонность, ставки и акции конкурентов. Ротация короткими блоками с
  перемешиванием это частично компенсирует; в отчёте отдельно проверяется, лидирует
  ли победитель во всех циклах, а не только по сумме.
- **Много вариантов — долго.** Чтобы поймать разницу CTR ~10–15%, на каждый вариант
  нужны десятки тысяч показов. Приложение само пишет, сколько ещё нужно.
- Замена обложки идёт перестановкой одобренных фото. Если Ozon для конкретной
  карточки отправит фото на повторную модерацию — увеличь «переходный период».
