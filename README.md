# A/B-тест обложки карточки Ozon по рекламному CTR

Крутит обложку одного товара по расписанию (вариант A → B → C → D → E → снова),
собирает показы/клики из Performance API и говорит, у какой обложки CTR выше и
значима ли разница.

## Как это работает

1. **Один раз** заливаем все 5 вариантов обложки в карточку и ждём модерации.
2. Дальше «переключение» — это просто **перестановка уже одобренных фото**
   (первое в списке = обложка). Повторной модерации не происходит, применяется быстро.
3. Раз в час `rotate.py` смотрит по расписанию, какой вариант должен быть активен,
   и переставляет обложку, если нужно.
4. Раз в час `collect.py` тянет дневную статистику рекламы и раскладывает её по
   вариантам. Первые сутки каждого блока не учитываются (переходный период).
5. `analyze.py` считает CTR по вариантам, проверяет значимость и пишет `report.md`.

Расписание по умолчанию: **5 вариантов × блок 3 дня × 2 цикла = 30 дней.**
Порядок во втором цикле перемешивается (сид фиксирован) — чтобы отделить эффект
обложки от дня недели и действий конкурентов.

## Настройка

```bash
pip install -r requirements.txt
cp .env.example .env          # вписать ключи Seller API и Performance API
```

Заполнить `config.toml`:

- `product_id` — ID товара. Узнать по артикулу: `python ozon_seller.py resolve ВАШ_OFFER_ID`
- `campaign_ids` — ID рекламных кампаний (продвижение в поиске / трафареты):
  `python ozon_performance.py campaigns`
- `start` — ближайшая полночь МСК
- 5 блоков `[[variants]]` — имя и публичный URL каждой обложки.
  `index 0` (первый) — то, что стоит сейчас.

Проверка ключей и текущих картинок:

```bash
python ozon_seller.py pictures ВАШ_PRODUCT_ID
```

## Запуск теста

```bash
python init.py --wait     # залить все варианты, дождаться модерации
python status.py          # посмотреть расписание и текущий блок
```

Дальше — по расписанию (см. «Хостинг»). Вручную в любой момент:

```bash
python rotate.py --dry-run   # что бы сделал сейчас
python rotate.py             # переключить обложку по расписанию
python collect.py            # обновить data/daily.csv
python analyze.py            # пересчитать report.md
```

## Хостинг: GitHub Actions (рекомендуется)

Не нужен сервер, работает 24/7, бесплатно.

1. Создать **приватный** репозиторий, залить туда эту папку.
2. Settings → Secrets and variables → Actions → добавить 4 секрета:
   `OZON_CLIENT_ID`, `OZON_API_KEY`, `OZON_PERF_CLIENT_ID`, `OZON_PERF_CLIENT_SECRET`.
3. Workflow `.github/workflows/abtest.yml` уже настроен на запуск раз в час.
   Он сам коммитит обновлённые `data/*.csv` и `report.md` обратно в репо —
   историю теста видно в коммитах, итог всегда в `report.md`.
4. Первый прогон — вкладка Actions → Run workflow.

> Cron в GitHub Actions может опаздывать на 5–15 минут — для почасовой ротации это неважно.

Альтернатива — свой сервер/VPS, крон:
```
7 * * * * cd /path/to/ozon-cover-abtest && /usr/bin/python3 rotate.py && /usr/bin/python3 collect.py && /usr/bin/python3 analyze.py
```

## Файлы

| файл | назначение |
|------|-----------|
| `config.toml` | все параметры теста |
| `init.py` | разовая заливка вариантов + ожидание модерации |
| `rotate.py` | переключение обложки по расписанию |
| `collect.py` | сбор статистики → `data/daily.csv` |
| `analyze.py` | расчёт CTR и значимости → `report.md` |
| `status.py` | где сейчас тест, полное расписание |
| `ozon_seller.py` | клиент Seller API (картинки) |
| `ozon_performance.py` | клиент Performance API (статистика) |
| `data/state.json` | журнал переключений |
| `data/daily.csv` | посуточная статистика по вариантам |
| `report.md` | итоговый отчёт |

## Ограничения метода

- **Тест по времени слабее одновременного сплита.** На CTR влияют день недели,
  сезонность, ставки и акции конкурентов. Ротация короткими блоками с
  перемешиванием это частично компенсирует, поэтому в отчёте есть проверка
  «лидер устойчив по циклам», а не только итоговый CTR.
- **Статистика рекламы — посуточная**, поэтому переключения выровнены по полуночи
  МСК и первые сутки блока отбрасываются.
- **5 вариантов — это долго.** Чтобы поймать разницу в CTR ~10–15%, на каждый
  вариант нужно накопить десятки тысяч показов. Если рекламного трафика мало —
  увеличь `block_days` или `cycles`, либо сократи число вариантов.
- Замена обложки идёт через перестановку одобренных фото. Если Ozon для конкретной
  карточки всё же отправит фото на повторную модерацию — увеличь `settle_hours`.
