A/B-тест обложки карточки Ozon по рекламному CTR

1. Подключение

Ключи хранятся локально в data/secrets.json (права 0600, в git не попадают).

ImgBB не подошёл — блокирует Россию. GitHub + CDN jsDelivr работают, ссылки постоянные. Как получить — см. README.

2. Товар

Артикул (offer_id) карточки, у которой будем менять обложку.

product_id
текущая обложка

3. Рекламные кампании

Отметь кампании «Продвижение в поиске» / трафареты, где видна обложка. Из них берутся показы и клики.

4. Варианты обложки

До 8 вариантов. Первый в списке — базовый (текущая обложка). Файлы загружаются в GitHub и раздаются через CDN, ссылку скачивает Ozon.

5. Параметры теста

Статистика рекламы Ozon обновляется с задержкой ~1–3 ч. Блоки короче ~6 часов дают менее точную привязку показов к варианту.

6. Запуск

  1. Залить все варианты в карточку и дождаться модерации Ozon (от минут до суток).
  2. Запустить тест — ротация начнётся с указанной даты (по умолчанию ближайшая полночь МСК).
